# 🎓 AI-Powered Education Management Portal

> An intelligent education management system with AI-driven academic insights, personalized recommendations, and comprehensive dashboards for students, teachers, and administrators.

---

## 📌 Features

### 👨‍🎓 Student Dashboard
- View personal academic performance
- Track grades across all subjects
- Get AI-powered study recommendations
- Identify weak and strong subjects
- Monitor attendance status

### 👨‍🏫 Teacher Dashboard
- View overall class performance
- Identify at-risk students
- Track top performers
- Get AI insights for class improvement
- Manage courses and students

### 🏛️ Admin Dashboard
- Complete system overview
- Student and teacher management
- Course and assignment tracking
- Subject-wise performance analysis
- AI-powered system insights

### 🤖 AI Intelligence Engine
- Performance analysis
- Weak subject detection
- At-risk student identification
- Personalized recommendations
- Risk level assessment
